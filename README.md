# ORION_LEX

Web y panel de administración del despacho Orion Lex.

```bash
npm install
npm run dev      # API http://localhost:4000/api/v1 · Web http://localhost:5173
```

Requisitos: Node 22+ y PostgreSQL (`BACKEND/.env`, ver `.env.example`).

La estructura y las reglas del proyecto están en [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
